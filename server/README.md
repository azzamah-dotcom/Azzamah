# خادم الإشعارات: طريقة التركيب على Cloudflare

هذا الخادم يرسل الأذان والإقامة و«هل صليت؟» وتذكير الأذكار إلى جوالات العائلة **والتطبيق مغلق**.
مجاني بالكامل، ولا يحتاج أي مفاتيح أو كلمات سر: ينشئ الخادم مفاتيحه بنفسه أول مرة.

المدة: حوالي 10 دقائق. يُفضَّل استخدام كمبيوتر لأن نسخ الكود ولصقه أسهل.

---

## ١. إنشاء الـ Worker

1. ادخل إلى **dash.cloudflare.com** (أنشئ حسابًا مجانيًا إن لم يكن لديك).
2. من القائمة الجانبية افتح **Workers & Pages** (قد يظهر باسم **Compute (Workers)**).
3. اضغط **Create** ثم **Create Worker** (أو **Start with Hello World**).
4. سمّه: `azkar-push` ثم اضغط **Deploy**.

## ٢. لصق الكود

1. افتح هذا الرابط، واضغط Ctrl+A ثم Ctrl+C لنسخ الكود كله:
   **https://raw.githubusercontent.com/azzamah-dotcom/Azzamah/main/server/worker.js**
2. ارجع إلى الـ Worker واضغط **Edit code**.
3. احذف كل الكود الموجود، والصق الكود الذي نسخته.
4. اضغط **Deploy**.

## ٣. إنشاء مخزن البيانات (KV)

1. من القائمة الجانبية: **Storage & Databases** ← **KV** (أو **Workers KV**).
2. اضغط **Create** (أو **Create a namespace**)، وسمّه: `azkar-subs`، ثم **Add**.

## ٤. ربط المخزن بالـ Worker

1. افتح الـ Worker `azkar-push` ← تبويب **Settings** ← **Bindings**.
2. اضغط **Add** ← **KV namespace**.
3. **Variable name**: اكتب `SUBS` بالأحرف الكبيرة تمامًا.
4. **KV namespace**: اختر `azkar-subs`.
5. اضغط **Save** (أو **Deploy**).

## ٥. التشغيل كل دقيقة (Cron)

1. في الـ Worker نفسه ← **Settings** ← **Trigger Events** (أو **Triggers**).
2. اضغط **Add** ← **Cron Triggers**.
3. اختر **Every minute**، أو اكتب: `* * * * *`
4. اضغط **Add** (أو **Deploy**).

## ٦. التأكد

افتح عنوان الـ Worker مع `/status` في آخره، مثل:

```
https://azkar-push.اسمك.workers.dev/status
```

يجب أن يظهر:

```
{"ok":true,"subscribers":0}
```

**أرسل لي هذا العنوان** (بدون `/status`)، وسأربطه بالتطبيق. بعدها يكفي أن يفتح كل فرد من العائلة التطبيق ويضغط «تفعيل» على التنبيهات.

---

### ملاحظات

- **الآيفون:** الإشعارات تعمل فقط إذا كان التطبيق مضافًا إلى الشاشة الرئيسية، ونظام iOS بإصدار 16.4 أو أحدث.
- **الصوت:** إشعار الجوال يصدر صوت التنبيه العادي. صوت الأذان الكامل يعمل والتطبيق مفتوح.
- **الخطة المجانية** من Cloudflare تكفي العائلة بسهولة.
- إذا ظهر عند فتح العنوان: `KV namespace SUBS is not bound` فراجع الخطوة ٤.

## تحديث الخادم لاحقًا

عند إضافة مزايا جديدة (مثل تطبيق الأطفال «صلاتي») يلزم تحديث الكود مرة واحدة:

1. افتح الرابط وانسخ الكود كله: **https://raw.githubusercontent.com/azzamah-dotcom/Azzamah/main/server/worker.js**
2. Cloudflare ← Workers & Pages ← `azkar-push` ← **Edit code**.
3. احذف الكود القديم، والصق الجديد، ثم **Deploy**.

المشتركون والمفاتيح محفوظة في مخزن KV، فلا يضيع شيء عند التحديث.
