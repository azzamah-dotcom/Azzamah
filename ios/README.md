# حصن الأذكار — تطبيق الآيفون

هذا المجلد يحوّل تطبيق «حصن الأذكار» الحالي إلى تطبيق آيفون حقيقي باستخدام **Capacitor**،
دون تغيير الموقع الحالي. التطبيق يستخدم نفس ملفات الموقع (الأذكار، الأوقات، القبلة، أولادي…)،
ويضيف فوقها مزايا لا يقدر عليها الموقع على الآيفون:

| الميزة | في الموقع | في التطبيق |
|---|---|---|
| الاهتزاز | نقرة خفيفة فقط (iOS 18+) | اهتزاز حقيقي من محرك الاهتزاز |
| التنبيهات والتطبيق مغلق | تحتاج خادم Cloudflare | تُجدول على الجوال نفسه، بلا إنترنت ولا خادم |
| صوت الأذان في التنبيه | صوت النظام فقط | صوت أذان مخصص (حتى 30 ثانية) |
| قائمة الأذكار | من الموقع | من الموقع، ومع نسخة داخل التطبيق تعمل بلا إنترنت |
| النشر | رابط | App Store |

---

## ما تحتاجه

1. **جهاز Mac** عليه **Xcode** (مجاني من App Store على الماك).
2. **Node.js** على الماك (من nodejs.org).
3. لتجربة التطبيق على جوالك: **Apple ID** عادي يكفي (التطبيق يعمل 7 أيام ثم تعيد تثبيته).
4. للنشر على App Store أو TestFlight للعائلة: **حساب مطوّر من آبل** (99$ سنويًا) من developer.apple.com.

## التشغيل لأول مرة على الماك

```bash
git clone https://github.com/azzamah-dotcom/Azzamah.git
cd Azzamah
git checkout ios-app
cd ios
npm install
npm run sync
npm run open
```

يفتح Xcode. بعدها:

1. اختر المشروع **App** من اليسار ← تبويب **Signing & Capabilities**.
2. في **Team** اختر حسابك (Apple ID أو حساب المطوّر).
3. إذا ظهر خطأ في **Bundle Identifier**، غيّره إلى شيء فريد، مثل `com.azzamah.hisnalazkar`.
4. **لا تضف** Push Notifications: التطبيق لا يحتاجها (تنبيهاته مجدولة على الجوال)، وحساب Apple ID المجاني لا يدعمها.
5. وصّل الآيفون بالكابل، واختره من أعلى Xcode، ثم اضغط ▶️ **Run**.
6. أول مرة على الجوال: الإعدادات ← عام ← VPN وإدارة الجهاز ← ثق بالمطوّر.

## ملاحظة عن Xcode الحديث

Xcode بنسخة iOS 26 SDK يشترط نظام النوافذ الجديد (UIScene). المشروع مهيّأ له في `AppDelegate.swift`
(يحتوي `SceneDelegate`) وفي `Info.plist` (`UIApplicationSceneManifest`). لا تعِد إنشاء مجلد `ios/` بأمر
`npx cap add ios`، لأن ذلك يرجع القالب القديم ويعود الخطأ «UIScene life cycle is required».

## إضافة صوت الأذان للتنبيهات

1. جهّز مقطع أذان **30 ثانية أو أقل** (حد آبل لأصوات التنبيهات).
2. حوّله إلى صيغة `caf` على الماك:
   ```bash
   afconvert -f caff -d LEI16@44100 -c 1 adhan.mp3 adhan.caf
   ```
3. اسحب `adhan.caf` إلى مجلد **App** داخل Xcode، وفعّل **Copy items if needed** و**Target: App**.

بدون الملف، تصدر التنبيهات بصوت النظام العادي.

## بعد أي تحديث للموقع

التطبيق يأخذ ملفات الموقع من المجلد الأعلى. لجلب آخر التعديلات:

```bash
git pull
cd ios
npm run sync
```

ثم **Run** من Xcode من جديد. أما **قائمة الأذكار** فتتحدّث وحدها داخل التطبيق من الموقع، بلا إعادة بناء.

## النشر على App Store

1. في Xcode: **Product ← Archive**.
2. **Distribute App ← App Store Connect ← Upload**.
3. في appstoreconnect.apple.com: أنشئ التطبيق، وأضف الوصف والصور، وفعّل **TestFlight** لتجربته مع العائلة أولًا،
   ثم **Submit for Review**.

## الملفات

| الملف | ماذا يفعل |
|---|---|
| `capacitor.config.json` | اسم التطبيق ومعرّفه وإعداداته |
| `native.js` | الطبقة الخاصة بالآيفون: التنبيهات المجدولة، الاهتزاز، تحديث القائمة |
| `build.mjs` | ينسخ ملفات الموقع إلى `www` ويضيف `native.js` |
| `ios/` | مشروع Xcode (الأيقونة، شاشة البدء، صلاحيات الموقع والبوصلة) |

### التنبيهات المجدولة على الجوال
- تُحسب أوقات الصلاة على الجوال لثلاثة أيام قادمة (حد آبل 64 تنبيهًا معلّقًا)، وتُجدّد كل مرة يُفتح التطبيق.
- تتبع إعدادات التنبيهات داخل التطبيق: الأذان، الإقامة ودقائقها، «هل صليت؟»، الأذكار، الصوت.
- الضغط على التنبيه يفتح القسم المناسب (الأوقات، أذكار الصباح، الجمعة…).
- **ملاحظة:** إذا لم يُفتح التطبيق 3 أيام متتالية تتوقف التنبيهات حتى يُفتح مرة.
